repositories (which use AGPL-3.0, a software license permitting commercial
use):

hosts/malware_domains traces back to mirror1.malwaredomains.com/files/justdomains,
a DNS-BH / malwaredomains.com (RiskAnalytics) data feed that is no longer
online. That project's own published terms stated the feed was "provided for
free for noncommercial use," and that "any use of this list commercially is
strictly prohibited without prior approval." This license preserves that
restriction for the compiled list, since a large majority of its entries
originate from that source. It does not apply to any other file in this
repository — see hosts/online_streaming_domains, which is an independent
compilation by T. Philip and is licensed separately (see
LICENSES/CC-BY-SA-4.0.txt).

See docs/DESIGN_SPEC.md §5 for a fuller discussion, including an honest note
that a bare list of domain names is arguably a list of facts rather than a
creative work under most jurisdictions' copyright law, so this license
should be read as a clearly stated request and intent rather than a settled
legal position.
